# Pinned dependency set for the cross-framework benchmark in benches/.
#
# Install into a throwaway environment with:
#
#     uv venv benches/.venv --python 3.13
#     uv pip install --python benches/.venv/bin/python -r benches/requirements-bench.txt
#
# These pins are not merely "what happened to resolve" — they are part of the
# measured configuration.  Several frameworks in this field switch JSON
# serializer depending on which fast library happens to be importable, so the
# presence of ujson/orjson/msgspec changes the number that gets published:
#
#   * Sanic      -> ujson      when ujson is importable (sanic/helpers.py)
#   * Litestar   -> msgspec    (msgspec.json.Encoder is its default codec)
#   * lauren     -> stdlib     (StdlibJSONEncoder is the default; OrjsonEncoder
#                               and MsgspecEncoder exist but are opt-in)
#   * BlackSheep -> stdlib     (essentials.json.dumps)
#   * FastAPI / Starlette / Falcon / Quart -> stdlib
#
# Leaving these to resolver luck would mean two machines could publish two
# different tables for the same "framework version".  See the serialization
# column in docs/comparisons/performance-benchmarks.md.

# lauren is the working tree under test, installed editable.  Its version comes
# from setuptools-scm, so it reads as e.g. 1.8.0.post17 on an untagged commit.
-e ..
